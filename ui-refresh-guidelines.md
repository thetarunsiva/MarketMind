# UI Refresh Guidelines — V2

## Purpose
Upgrade the frontend from a generic AI-generated appearance into a more polished B2B intelligence product experience.

This is not a flashy redesign.
This is a credibility redesign.

---

## Desired Product Feel
The UI should feel:
- premium
- analytical
- trustworthy
- modern
- structured
- business-ready

The UI should not feel:
- cluttered
- over-animated
- toy-like
- generic AI boilerplate
- overly colorful
- crowded with cards that all look the same

---

## Layout Principles

### 1. Strong page shell
Use a consistent shell:
- top header
- left navigation or stable tab system
- clear page title
- compact status chips
- spacious content region

### 2. Visual hierarchy
Most important information should be visible first:
- recommendation spotlight
- signal summaries
- current mode
- key changes
- evidence links
- GEO insights

### 3. Better grouping
Group related items into meaningful sections:
- Recommendation Spotlight
- Market Signals
- GEO Validation
- Competitor Comparison
- Evidence and Sources
- Predictive Preview

---

## Typography
Use stronger contrast between:
- title
- subtitle
- section heading
- meta text
- evidence text

Avoid everything looking like the same font size and weight.

---

## Cards
Cards should feel more premium:
- softer but confident borders
- cleaner spacing
- sharper labels
- better chip/badge system
- limited decorative noise

Cards must not all look identical.
Important cards should feel important.

---

## Color Usage
Use color intentionally:
- neutral base
- 1 main accent
- 1 secondary accent
- clear status colors for demo/live/warning/confidence

Avoid random gradients everywhere.

---

## Required V2 Surfaces

### 1. Recommendation Spotlight
A hero card for the main recommendation for the selected target company.

### 2. Signal Contribution Visualization
Use a donut/pie chart to show:
- website intelligence contribution
- GEO contribution

### 3. GEO Validation Panel
Show:
- prompt coverage
- surfaced competitors
- visibility patterns
- why the recommendation is GEO-supported

### 4. Evidence Table or Evidence Drawer
Show:
- source
- snippet
- competitor
- signal type

### 5. Predictive Preview
A small clearly-labeled preview block.
Must not dominate the screen.

---

## Mode Visibility
Clearly show:
- Demo Mode (Seeded)
- Live Mode
- Hybrid Mode if relevant

This must feel intentional and professional.

---

## Empty and Error States
They should feel like product states, not failures.
Use clear language such as:
- No live signals captured yet
- Demo signals available
- Snapshot captured, insights pending
- GEO records unavailable for this prompt set

---

## Responsiveness
The desktop laptop experience should be primary.
Do not break common widths.
Cards should not collapse into chaos.

---

## Forbidden UI Mistakes
- giant walls of text
- too many badges
- meaningless gradients
- weak spacing
- all cards visually identical
- unclear hierarchy
- hidden evidence
- GEO feeling bolted on
