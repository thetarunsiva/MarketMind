# UI Copy Compression Guidelines

## Purpose
Reduce verbose, AI-generated feeling text across the app and replace it with tighter, more executive-friendly product copy.

---

## Writing Goals
The UI copy should feel:
- concise
- clear
- strategic
- confident
- product-grade

The UI copy should not feel:
- essay-like
- overly explanatory
- repetitive
- apologetic
- vague AI fluff

---

## Rules

### 1. Lead with the signal
Show the important number, label, or conclusion first.

### 2. Short supporting text
Supporting text should usually be one short sentence, not a paragraph.

### 3. Prefer structure over prose
Use:
- bold labels
- chips
- compact metrics
- concise bullets
instead of long blocks of copy.

### 4. Compress recommendation text
Top-level recommendation copy should be:
- 1 short executive line
- 1 short "why it matters" line
- 1 short next action line

### 5. Use stronger metric emphasis
Important numbers should use:
- larger font size
- heavier weight
- shorter labels

### 6. Keep evidence tight
Evidence snippets should be short, scannable, and obviously tied to a source.

---

## Examples

### Bad
"This recommendation is based on a combination of website-based competitive positioning analysis and GEO support signals derived from language model visibility patterns across multiple buyer-intent prompts."

### Better
"**Backed by:** competitor pages + GEO prompt signals"

---

### Bad
"The market appears to be moving in a direction that suggests workflow integration is becoming an increasingly common expectation among buyers."

### Better
"**Trend:** workflow integration is becoming table stakes"

---

### Bad
"This competitor seems to be underrepresented across language-model-generated recommendation surfaces."

### Better
"**GEO gap:** weak LLM visibility"

---

## Page-Level Guidance

### Dashboard
- fewer paragraphs
- more metrics
- one-line summaries only

### Insights
- short title
- one-line recommendation
- one-line rationale
- compact evidence block

### GEO
- prompt count
- surfaced brands
- frequency
- short interpretation

### Whitespace
- short opportunity statement
- short why-now statement
- short suggested test

---

## Typography Direction
Use stronger contrast between:
- large headline metrics
- section headings
- supporting metadata
- evidence text

Key numbers should be more prominent than description text.
